# GitHub Collaboration Practice

이 프로젝트는 GitHub 협업 실습을 위해 만든 저장소입니다. 
현재 작업 브랜치는 `AAA`이며, main 브랜치에서 pull을 받은 뒤 기능별 작업과 문서 정리를 진행하고 있습니다.

## 프로젝트 소개

이 저장소는 간단한 연락처 페이지를 만들고, GitHub 협업 흐름을 익히기 위한 실습 프로젝트입니다.

주요 목표는 다음과 같습니다.

- GitHub에서 브랜치를 생성하고 작업하는 경험
- main 브랜치에서 최신 내용을 pull받는 과정 이해
- HTML 기반 연락처 페이지 구성
- README를 통해 프로젝트 설명 문서화

## 진행한 작업

### 1. 브랜치 작업
- `main` 브랜치에서 최신 내용을 pull 받음
- 작업용 브랜치 `AAA` 생성 및 사용
- GitHub 협업 흐름에 맞게 브랜치 기반 작업 진행

### 2. 연락처 페이지 제작
- HTML만으로 간단한 문의 폼 구성
- 이름, 이메일, 연락처, 문의 내용 입력란 추가
- 제출 및 초기화 버튼 포함
- 기본적인 웹 페이지 형태로 동작하도록 구성

### 3. 문서화
- 프로젝트 설명을 담는 README 작성
- 작업 내용, 실행 방법, 협업 규칙 정리

## 포함된 파일

- `contact.html`: 연락처 입력 폼이 포함된 페이지
- `README.md`: 프로젝트 설명 및 작업 내역 문서

## 실행 방법

브라우저에서 `contact.html` 파일을 직접 열면 확인할 수 있습니다.

```bash
cd AA
start contact.html
```

## 협업 규칙

- `main` 브랜치에서 직접 작업하지 않기
- 기능별로 브랜치 생성 후 작업하기
- 작업이 끝나면 커밋 메시지를 명확하게 남기기
- 변경 내용을 공유하기 위해 PR 사용하기

## 현재 상태

- 브랜치: `AAA`
- 작업 내용: 프로젝트 소개 문서 작성, 연락처 페이지 구성
- 목적: GitHub 협업 실습 및 브랜치 기반 개발 경험 쌓기
