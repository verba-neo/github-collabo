# GitHub Collabo

## 프로젝트 개요
이 저장소는 GitHub 협업 실습을 위한 프로젝트입니다.
현재 작업 브랜치는 `BBB`이며, 간단한 소개 페이지를 만들어 보며 브랜치 기반 작업과 커밋 관리 흐름을 연습하고 있습니다.

## 작업 내용
- 소개 페이지 파일인 `about.html`을 생성했습니다.
- 외부 CSS 파일 없이 HTML만으로 페이지를 구성했습니다.
- 기본적인 회사/팀 소개 형식으로 내용을 작성했습니다.
- 페이지에는 다음 섹션을 포함했습니다.
  - About Us
  - 우리의 이야기
  - 핵심 가치
  - 팀 소개
  - 미션
  - Contact 정보

## 파일 구성
- [about.html](about.html): CSS 없이 작성한 소개 페이지

## 현재 상태
- 브랜치: `BBB`
- 작업 내용: 정적 소개 페이지 제작 완료
- 커밋 이력: `Add about page`

## 참고
이 프로젝트는 빠르게 HTML 구조를 구성하고, GitHub 협업 과정에서 브랜치와 커밋을 익히는 데 초점을 두고 있습니다.
